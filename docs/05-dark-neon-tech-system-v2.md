# GOBI88 Dark Neon Tech Visual System v2

**Status:** Active owner-directed visual theme  
**Date:** 2026-08-02  
**Supersedes:** v1 palette/material treatment; v1 hierarchy and four-mode logic remain valid

## Core formula

> Dark field + colorful luminous gradient + neon edge + glass pill UI + engineered metal.

The image must remain recognizably GOBI88 even when multiple accent colors appear. Deep navy, pearl white, signal red, canonical GOBI, B-88, and the official wordmark remain the anchors.

## Visual ratio

| Component | Recommended share |
|---|---:|
| Deep navy / near-black structure | 65–75% |
| Pearl white information and character surfaces | 10–20% |
| Signal red brand/action light | 8–12% |
| Secondary colorful luminous accents | 5–12% |

## Secondary luminous palette

- Electric blue: `#2F80FF`
- Cobalt: `#2457D6`
- Cyan: `#20D9FF`
- Teal: `#00C7B1`
- Amber: `#FFB547`
- Restrained orange: `#FF6A2A`

Secondary colors appear as gradient light, refraction, glow, emissive seam, chart line, icon, or pill status. They must not replace the official red/white/navy brand anchors.

Still prohibited:

- Pink, hot pink, and magenta.
- Pastel candy palettes.
- Flat rainbow backgrounds.
- Generic casino gold, fire, coin rain, or jackpot effects.

## Material language

- Brushed gunmetal frames.
- Satin chrome bevels.
- Anodized navy metal.
- Smoked and translucent glass.
- Clear acrylic pill controls.
- Carbon-fiber texture used sparingly.
- Emissive red/blue/cyan edge strips.

Metal should provide physical structure; glow should communicate state or action.

## UI language

- Rounded pill controls and status chips.
- Nested metal rails and modular cards.
- Glass panels with 8–18% opacity.
- One primary pill action per composition.
- Secondary UI may use dots, bars, grids, waveforms, and abstract graphs.
- Never use invented win rates, balances, percentages, or performance claims.
- All final data must be verified and composited as controlled typography.

## Updated mode treatment

1. **Neon Cinema** — former Signal Cinema with deeper background and multicolor luminous depth.
2. **Glow UI** — former Type Strike with dark field, white type, glass pills, and colorful status light.
3. **Metal Pulse** — former Breakout Frame with brushed-metal portal and emissive seams.
4. **Holo Editorial** — former Editorial Mask with dark portrait crop, pill badges, metal rails, and gradient halo.

## Glow limits

- Preserve readable black/navy shadows.
- Avoid blooming across eyes, cheek marks, logo, or subtitles.
- Maximum two dominant glow hues plus signal red in one frame.
- Use one bright focal glow; secondary glows remain restrained.
- Never use glow as a substitute for hierarchy.

# Gobiverse

**Domain:** [gobiverse.com](https://gobiverse.com)  
**Repository:** [github.com/9dbit/Gobiverse](https://github.com/9dbit/Gobiverse)

Gobiverse adalah platform gaming Indonesia berbasis **content-led commerce**: konten dan tools membantu gamer mengambil keputusan, komunitas serta turnamen membangun retensi, lalu katalog gear menjadi lapisan monetisasi.

## Positioning

> **Gobiverse — Main Lebih Cerdas.**

Fokus awal bukan portal berita umum dan bukan ecommerce generik. Gobiverse dimulai sebagai:

1. pusat build, counter, meta, dan tools Mobile Legends;
2. direktori turnamen esports Indonesia;
3. review dan katalog gaming gear;
4. ecommerce/affiliate gaming setelah traffic dan trust terbentuk.

## Status

Repository sedang berada pada tahap **product foundation**. Implementasi aplikasi akan dilakukan dengan Replit Agent setelah dokumen scope dan aturan pengerjaan direview.

## Replit handoff

1. Import repository ini dari GitHub ke Replit.
2. Pastikan Agent membaca `replit.md` dan seluruh dokumen di folder `docs/`.
3. Tempel isi `docs/05_REPLIT_MASTER_PROMPT.md` sebagai prompt pertama.
4. Kerjakan satu milestone pada feature branch.
5. Jalankan validation gate dan simpan screenshot sebelum meminta approval.

Jangan menyimpan secret, token, API key, atau kredensial di repository.
